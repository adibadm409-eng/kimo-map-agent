# فهرس الذاكرة — Memory Index

خريطة ملفات الذاكرة والوثائق في مشروع مدير العقارات.

## ملفات الذاكرة (تُقرأ عند بدء الجلسة)
| الملف | المحتوى | متى يُقرأ |
|---|---|---|
| `memory/ARCHITECTURE.md` | بنية التطبيق والأجزاء الرئيسية | أي مهمة تحتاج فهم البنية |
| `memory/DECISIONS.md` | القرارات المهمة وأسبابها | قبل أي قرار جديد، أو عند "لماذا هكذا؟" |
| `memory/SESSION_LOG.md` | سجل الجلسات: ما أنجزناه ومتى | عند "تذكر/ما ذا فعلنا" |
| `memory/CHANGELOG.md` | سجل الالتزامات تلقائياً (خطاف git) | عند "راجع التعديلات/ما تغيّر" |

## وثائق المشروع الموجودة (لا تُعاد كتابتها في الذاكرة)
| الوثيقة | المحتوى |
|---|---|
| `AGENTS.md` | قواعد العمل وبروتوكول الذاكرة |
| `DESIGN.md` | نظام التصميم (ألوان، خطوط، أنماط) |
| `PROBLEMS_LOG.md` | الدروس والفخاخ التقنية (الملف الأساسي للدروس) |
| `MAPS_DOCUMENTATION.md` | توثيق الخرائط |
| `docs/RUN.md` | طريقة التشغيل |
| `~/schema.sql` | مخطط قاعدة البيانات |

## القواعد
- أجب بالعربية دائماً.
- عند الشك في أمر ما: اقرأ المصدر قبل الافتراض.
- ملفات الذاكرة ملكية فريق التطوير — تُحدَّث بعد كل مهمة.
