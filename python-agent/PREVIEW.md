# PREVIEW — محرك Kimo (النسخة الأصلية)

هذا المجلد `kimo-engine-preview/` يحتوي على **نسخة حرفية كاملة غير معدّلة** من
محرك وكيل **Kimo** المستخرج من التطبيق الأصلي (مدير العقارات / `my-app`).

## ما الذي تم نسخه (كمرآة حرفية)
- `assistant/` — كامل زمن تشغيل الوكيل (الحلقة الرئيسية، LLM، المهارات،
  الأدوات، التخزين، الملفات، المحادثة الصوتية...).
- `agent/` — سجل الأدوات (registry)، الكتالوج، الاستعلام، الـ CRUD،
  التحليلات، أدوات المجال، استيراد المشاريع.
- `domain/` — نموذج المجال (المشاريع والمراجع).

## القاعدة
> **هذه نسخة معاينة (preview) فقط — بلا أي تعديل.**

لا تُعدَّل الملفات هنا. هي المرجع المرجِّح لسلوك المحرك الأصلي أثناء بناء
النسخة البديلة بمحرك بايثون في `python-agent/` (خارج هذا المجلد).

عُدِّدت النسخة عبر `cp -r` والتحقق بـ `diff -rq` فكانت مطابقة تماماً
(`PREVIEW_EXACT_COPY_OK`).
