# AGENTS.md — Python Agent

نسخة من تطبيق **مدير العقارات** (Property Manager / `my-app`)،
مخصّصة لتطوير الوكيل (agent) ليعمل بمحرك **بايثون** قوي وسريع ومرن.

## النطاق
- يحتفظ بنموذج المجال وتجربة الاستخدام من تطبيق مدير العقارات.
- يستبدل طبقة الوكيل/الـ runtime بمحرك بايثون لأداء عالٍ وتكرار سريع ومرونة في الأدوات والسكربتات.

## العلاقة بتطبيق مدير العقارات
هذا المشروع هو نسخة من تطبيق مدير العقارات، معدّلة لتشغيل الوكيل تحت بيئة
بايثون قوية بدل منظومة JS/TS.
