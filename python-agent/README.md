# Python Agent

**Python Agent** is a fork/variant of the **Property Manager** app (`my-app`),
re-purposed for **agent development**.

While the original Property Manager is built on a TypeScript/Expo stack, this
edition is specialized to run the agent on a **powerful, fast, and flexible
Python engine**.

## Purpose
- Keep the domain model and UX of the Property Manager app.
- Replace the runtime/agent layer with a Python-powered engine for:
  - high performance
  - fast iteration
  - flexible tooling and scripting

## Relationship to Property Manager
This project is **a version of the Property Manager app**, adapted so the agent
works under a strong Python runtime instead of the JS/TS stack.
